# Sample project and exports

These are real outputs from the sample project that opens with the app, generated by the final
build. Use them to preview the deliverable without clicking through the UI, or as a reference for
what the exports contain.

| File | What it is |
|---|---|
| `demo-project.json` | The sample kitchen run project file (7 cabinets, 16 ft wall / 8 ft ceiling / 36 in counter) — open it with **Open project** in the app; it lands on the guided run overview. |
| `sample-plan-set.pdf` | Full shop plan set: cover/schedule, general arrangement, whole-cabinet sheets, component technical drawings, cut list, material plan (purchase quantities, saw cuts, offcuts, solid board feet), sheet nesting with per-sheet cut sequences, door/drawer and hardware schedules, assembly order, notes/sign-off. Tabloid landscape, 95 pages (unique component scope). |
| `sample-shop-drawings-R2000.dxf` | CAD drawing (`all` mode: part layouts, nesting, cabinet views) for AutoCAD/CNC. DXF AC1015. |
| `sample-shop-drawings-R2000.dwg` | Real AutoCAD R2000 DWG of the same drawing, written by the vendored nasjidwg library and validated with LibreDWG. |

Regenerate from the app (**Plans & export**), or from Node as in the README. The sample is a
design demonstration, not a commissioned cabinet: check the site, hardware and code requirements
for your own project.
